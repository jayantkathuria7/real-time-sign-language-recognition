## File Index

`artifacts/`
- **`encoders/`**: Contains the label encoders used to encode the target variable, saved each time a new model is trained.
- **`plots/`**: Contains all plots generated during model training from _`notebook/model_training.ipynb`_.
- **`reports/`**: Contains the classification report of the model performance.
- **`test_data.npz`**: Contains the test data saved during training for evaluation.

`assets/`
- Contains the demo video of the project and a PowerPoint presentation explaining the project.

`config/`
- **`app_config.py`**: Contains configuration settings for real-time recognition, including prediction frequency, smoothing, sign stability, audio playback, and camera selection.
- **`app_state.py`**: Manages real-time prediction state, confidence, translations, and audio playback control.
- **`languages.py`**: Defines supported languages, their language codes (used while translating through the API), and keyboard codes.
- **`model_config.py`**: Contains model training, video preprocessing, and model version configuration settings.
- **`paths.py`**: Defines and manages project-wide paths for data, models, fonts, and artifacts.

`data/`
- **`audio/`**: Contains audio files for each word in each supported language, generated by _`scripts/build_translations.py`_.
- **`fonts/`**: Contains font assets used for rendering fonts on frames.
- **`videos/`**: Contains the raw videos.
- **`resized_videos/`**: Contains the videos after resizing them to a consistent size, generated by _`scripts/resize_videos.py`_.
- **`translations/`**: Contains translations of each word for each supported language, stored as a `.json` file to reduce the overhead of translating in real time, generated by _`scripts/build_translations.py`_.
- **`sequences/`**: Contains fixed-length keypoint sequences (`X_sequences.npy`) and corresponding labels (`y_labels.npy`) generated from the video dataset by _`scripts/build_dataset.py`_.

`models/`
- **`archive/`**: Contains previously trained model versions.
- **`current/`**: Contains the currently active trained models used by the application.
- **`models_metadata.json`**: Stores metadata and version information for the trained models.

`notebook/model_training.ipynb`
- Contains the code and experiments used to train the models.

`scripts/`
- **`resize_videos.py`**: Processes all videos and resizes them to a target size to ensure consistency.
- **`build_dataset.py`**: Processes all videos and generates sequences and labels for model training.
- **`build_translations.py`**: Generates translations and audio files for each word in each language.
- **`train_model.py`**: Trains the model using the prepared training data.
- **`setup_project.py`**: Automates project setup by preparing videos, generating training data, training the model, and creating translations.
- **`run_app.py`**: Entry point for launching the real-time sign language recognition application

`src/audio/`
- **`generator.py`**: Contains the helper function used to generate and save audio from translated text using gTTS.
- **`player.py`**: Contains functions for playing saved audio and managing automatic audio playback during real-time recognition.

`src/data/`
- Contains files used to preprocess data before model training.
- **`augmentation.py`**: Performs data augmentation by generating synthetic data.
- **`dataset_builder.py`**: Contains helper functions to process videos and save generated data during _`scripts/build_dataset.py`_.
- **`feature_extraction.py`**: Performs feature extraction/engineering.
- **`keypoints_extraction.py`**: Reads videos and extracts and normalizes hand keypoints using MediaPipe.
- **`video_resize.py`**: Contains helper functions for _`scripts/resize_videos.py`_.

`src/input/`
- **`keyboard_input.py`**: Handles keyboard controls for quitting, language selection, and manual or automatic audio playback.

`src/model/`
- **`evaluation/metrics.py`**: Contains functions for evaluating models, calculating metrics, and saving evaluation reports and plots.
- **`training/callbacks.py`**: Contains training callbacks for early stopping, learning rate scheduling, and adaptive learning rate reduction.
- **`training/data.py`**: Contains functions for loading, splitting, encoding, normalizing, and augmenting data for model training.
- **`training/model.py`**: Handles saving, loading, archiving, and versioning trained models and their label encoders.
- **`training/trainer.py`**: Contains the function used to train the model in _`src/pipelines/training_pipeline.py`_.
- **`architecture.py`**: Defines the CNN-LSTM model.

`src/pipelines/`
- **`evaluation_pipeline.py`**: Evaluates the current model and saves its metadata, dataset information, and evaluation metrics.
- **`training_pipeline.py`**: Orchestrates model building, training, evaluation, and saving of the trained model.
- **`translation_pipeline.py`**: Orchestrates translation generation, audio creation, and saving translation data.
- **`realtime_pipeline.py`**: Main real-time recognition pipeline that integrates camera input, MediaPipe processing, model prediction, translation, audio playback, UI display, and keyboard controls.

`src/recognition/`
- **`prediction.py`**: Handles keypoint preprocessing, model prediction, prediction smoothing, confidence filtering, and audio triggering during real-time recognition.

`src/translations/`
- **`translator.py`**: Contains the helper function used to translate words into supported languages using GoogleTranslator.
- **`translation_store.py`**: Handles saving, loading, retrieving, and validating translation data and audio files.

`src/ui/`
- **`display.py`**: Handles rendering the real-time video frame with predictions, translations, confidence, FPS, and audio status.
- **`landmarks.py`**: Handles drawing detected hand landmarks on the video frames.

`.gitignore`
- Contains files to exclude from Git tracking.

`Readme.md`
- Provides an overview and documentation of the project.

`requirements.txt`
- Lists the Python libraries required to run the project.

`file_index.md`
- Provides a description of the project files and their purpose.

`file_tree.md`
- Shows the structure and organization of the project files and directories.
